# SwiftPuzzles

> Русская версия: [README.ru.md](README.ru.md)

![status](https://img.shields.io/badge/status-WIP-orange)

An iOS game for learning Swift: assemble a puzzle with a concept diagram —
get a short theory summary with a code sample in return. Solved topics come
back for review as a "find the missing piece" quiz with spaced repetition
(Leitner system: 1, 3, 7, 14, 30 days).

Status: **WIP**, MVP in development (see "Roadmap" below).

## How it was built

All the code was generated by an AI assistant (Claude Code) — I didn't write
it by hand. I set the direction and made the decisions:

- broke the idea into MVP stages and worked one step at a time;
- chose the architecture: content as JSON in the bundle, progress in
  SwiftData, pieces cut by geometry instead of pre-sliced files, Leitner
  repetition intervals;
- read and understood each generated change, including the key Swift concepts
  behind it: SwiftUI gestures and animations, grid geometry, SwiftData.

## Tech stack

- SwiftUI, iOS 18.6+, Swift language mode 5
- No third-party dependencies
- Unit tests — Swift Testing, UI tests — XCTest
- Build and tests via `xcodebuild`

## Architecture and key decisions

- **Content in the bundle, progress in SwiftData.** Topics, theory, code
  samples and images live in `content.json` + assets and are validated at
  launch (duplicate ids, broken references, missing images). Only user
  progress is stored in SwiftData, so content updates need no DB migrations.
- **The image is not cut into files.** The whole diagram is drawn at board
  size, shifted with `offset` and clipped to the cell — so one image works
  with any grid (3×4 / 4×5 / 5×6, chosen in Settings).
- **Rectangular pieces without tabs**, Sattolo shuffle (no piece starts in
  its correct slot). Drag & drop swaps two pieces; mismatched neighbours
  show a dark line between them.
- **Board logic lives in pure types** (`PuzzleBoard`, `GridSize`) — covered
  by unit tests, independent of the UI.

## Running

Requires Xcode with iOS 18.6+ support.

```bash
# build
xcodebuild -project SwiftPuzzles.xcodeproj -scheme SwiftPuzzles \
  -destination 'platform=iOS Simulator,name=iPhone 18 Pro' build

# unit tests
xcodebuild -project SwiftPuzzles.xcodeproj -scheme SwiftPuzzles \
  -destination 'platform=iOS Simulator,name=iPhone 18 Pro' test \
  -only-testing:SwiftPuzzlesTests
```

Or open `SwiftPuzzles.xcodeproj` in Xcode and run on a simulator.
