# SwiftPuzzles

> English version: [README.md](README.md)

![status](https://img.shields.io/badge/status-WIP-orange)

iOS-игра для изучения Swift: собираешь пазл со схемой концепции —
получаешь короткую теорию с примером кода. Решённые темы возвращаются
на повторение в режиме «угадай недостающий кусок» с интервальным
повторением (система Лейтнера: 1, 3, 7, 14, 30 дней).

Статус: **WIP**, MVP в разработке (см. «Планы» ниже).

## Как сделано

Весь код сгенерирован ИИ-ассистентом (Claude Code) — я не писал его руками.
Я задавал направление и принимал решения:

- разбил идею на этапы MVP и двигался по одному шагу за раз;
- выбрал архитектуру: контент в JSON в бандле, прогресс в SwiftData,
  нарезка картинки геометрией вместо готовых файлов, интервалы повторения по Лейтнеру;
- читал и разбирал каждое сгенерированное изменение, понимая ключевые
  концепции Swift за ним: жесты и анимации SwiftUI, геометрия сетки, SwiftData.

## Стек

- SwiftUI, iOS 18.6+, Swift language mode 5
- Без сторонних зависимостей
- Юнит-тесты — Swift Testing, UI-тесты — XCTest
- Сборка и тесты — через `xcodebuild`

## Архитектура и ключевые решения

- **Контент — в бандле, прогресс — в SwiftData.** Темы, теория, примеры
  кода и картинки лежат в `content.json` + ассеты и валидируются при
  запуске (дубликаты id, битые ссылки, отсутствующие картинки). В SwiftData
  хранится только прогресс прохождения. Контент обновляется без миграций БД.
- **Картинка не режется на файлы.** Целая схема рисуется размером с доску,
  сдвигается `offset` и обрезается `clipped()` по ячейке — поэтому одна
  картинка работает на любой сетке (3×4 / 4×5 / 5×6, выбор в настройках).
- **Прямоугольные куски без «ушек»**, перемешивание — Sattolo
  (ни один кусок не начинает на своём месте). Drag & drop меняет два куска
  местами; между неподходящими соседями видна тёмная линия.
- **Логика доски вынесена в чистые типы** (`PuzzleBoard`, `GridSize`) —
  покрыта юнит-тестами, не зависит от UI.

## Запуск

Требуется Xcode с поддержкой iOS 18.6+.

```bash
# сборка
xcodebuild -project SwiftPuzzles.xcodeproj -scheme SwiftPuzzles \
  -destination 'platform=iOS Simulator,name=iPhone 18 Pro' build

# юнит-тесты
xcodebuild -project SwiftPuzzles.xcodeproj -scheme SwiftPuzzles \
  -destination 'platform=iOS Simulator,name=iPhone 18 Pro' test \
  -only-testing:SwiftPuzzlesTests
```

Или откройте `SwiftPuzzles.xcodeproj` в Xcode и запустите на симуляторе.

## Планы

- Экран теории-награды после сборки (с подсветкой синтаксиса кода)
- Прогресс на SwiftData + интервальное повторение (Лейтнер)
- Режим повторения «недостающий кусок»: 1 правильный + 2 «битых» варианта
- Склейка подходящих кусков в группы, движение группы целиком
- Мета-пазл «Карта Swift» из освоенных тем
- 10 тем с настоящими схемами (сейчас 5 тем на одной мок-схеме)
- Полировка: хаптики, анимации, иконка, тёмная тема
